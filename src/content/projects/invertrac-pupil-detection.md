Senior capstone project (team of 4) building InverTrac — an inversion-tracking algorithm for
pupil detection that runs on combined low CPU/GPU power using only a personal computer's
webcam, with no specialized hardware.

- Devised and implemented the InverTrac algorithm, using morphological operators to strip
  corneal reflections and reduce noise ahead of pupil identification — cutting processing
  overhead without sacrificing tracking accuracy.
- Built a user-centric GUI application in HTML, CSS, JavaScript, and Python, improving user
  satisfaction by 50%.
- The underlying technique was later published in a peer-reviewed journal (see Publications).
